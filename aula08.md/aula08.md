### O que é Risco?

> Um risco não é uma certeza de ocorrência, é uma probabilidade, e deve ser tratado preventivamente para que um problema não ocorra.

---

### Matriz de Risco

Ferramenta visual para organizar e priorizar riscos.

- **Probabilidade:** A a E (menor a maior)
- **Impacto:** 1 a 5 (menor a maior)

---

### Tipos de Risco

| Tipo | Exemplo |
|---|---|
| **Técnico** | API lenta |
| **Negócio** | Perda financeira |
| **Operacional** | Backup falhou |
| **Humano** | Erro de deploy |

> Risco zero não existe. 

### Cada risco exige um tipo de teste

| Risco | Teste |
|---|---|
| Segurança | Pentest |
| Lentidão | Stress test |
| Integração | Teste de API |
| Bugs | Teste funcional |
| Regressão | Automação |
