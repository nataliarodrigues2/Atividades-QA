## Debug

### Conceito 

É o processo voltado para identificar e remover erros existentes no código.

### Importância 

O debug melhora a gestão de tempo e produtividade. É nítido que corrigir bugs manualmente pode ser uma tarefa demorada e frustrante.

# Processo de Debug no VS Code

Passos:

1. Abrir o projeto no VS Code;
2. Acessar a aba "Run and Debug";
3. Selecionar Node.js;
4. Criar a configuração de Debug;
5. Adicionar breakpoints no código;
6. Executar a aplicação;
7. Analisar variáveis e fluxo de execução.
